  - עץ השלוחות הנוכחי, עם הגדרות והפניות.

  - דוח פערים.

**⚠️ מה שהמשתמשת עושה בדף נשמר באחסון של הדף, לא במאגר:**
- `decisions/<node_id>`: השיוך. `action`: `none` (חדשה) / `same` (קיימת) / `merge` (מאוחדת). הערך `routing` ישן, ומשמעותו סוג "תפריט מורחב".
- `nodeprops/<node_id>`: הערכים `planned_type`, `special_build`, `note_mark` (או `note_marks` הישן), `notes[]` ו-`title`.
- **החזרה לבסיס הנתונים:**
  1. מורידים את שני האוספים בעזרת `ArtifactData list` עם `out_dir`.
  2. מריצים `python3 -m app.planning.apply_decisions <decisions-dir> --props <nodeprops-dir>`.
  3. מריצים שוב את `analyze`.
- ב-28.10 היו 32 החלטות ו-1 מסמך `nodeprops`.
