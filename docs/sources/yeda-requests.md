# בקשות לשדות מזהים מידע פון

הבקשות נאספו מניתוח התיעוד ומקובץ ההאזנות של יום המדגם (27.3.2026). המטרה: לשייך כל האזנה, באופן חד-משמעי, לשלוחה, להקלטה ולמרצה.

## יומן האזנות (`/api/data/sfu-list/`)

| שדה מבוקש | למה |
|---|---|
| `sclass_id` | היום מגיעים רק נתיב ושם. כשהנתיב משתנה, השיוך לשלוחה נשבר |
| `streamfile_id` | `record_name` מופיע לפעמים כנתיב, לפעמים כשם קובץ ולפעמים ככותרת. בלי מזהה אי אפשר לזהות הקלטה בוודאות |
| `call_id` | מזהה שיחה. בלעדיו אי אפשר לחבר כמה האזנות לאותה שיחה |
| `start_position`, `end_position` | מאיזה מקום בקובץ התחילה ההאזנה, ואיפה הסתיימה. נדרש לחישוב השלמה מדויק ולהבנת "חזרה למקום האחרון" |
| זמנים עם אזור זמן (ISO + offset) | היום הזמנים מגיעים בלי אזור זמן, וזה יוצר אי-ודאות במעברי שעון קיץ וחורף |
| תיעוד ברור: לפי איזה זמן מסנן `date=` (התחלה או סיום, ובאיזה אזור זמן) | ביום המדגם הופיעו האזנות מאחרי חצות (Q-101) |

## קטלוג הקלטות (`/api/streamfile/`)

| שדה מבוקש | למה |
|---|---|
| `sclass_id` (או רשימת שלוחות) | באילו שלוחות הקובץ נמצא |
| `source` מלא: טלפון, העלאה, TTS | השדה קיים היום, אבל תמיד מגיע `null` |
| `recorded_by_phone` או `uploaded_by_user_id` | מי הקליט או העלה. היום הטלפון מופיע רק בתוך שם הקובץ, ורק בהקלטות מהטלפון |
| `status` ו-`published_at` | ממתין לפרסום, פורסם או פג תוקף, ומתי פורסם בפועל. נדרש להפרדה בין מועד הגשה למועד פרסום |
| `replaces_streamfile_id` | קישור לגרסה קודמת, כשמעלים שוב את אותו שיעור |
| סינון לפי `sclass_id` ו-`created_since` | כדי לשלוף רק הקלטות חדשות של שלוחה מסוימת, בלי לסרוק 222 אלף קבצים |
| שדה מחיקה (`deleted_at`) | כדי לדעת שקובץ נמחק, ולא רק שהוא חסר |

## שלוחות (`/api/system/sclass/`)

| שדה מבוקש | למה |
|---|---|
| `parent_id` | היום צריך לגזור את ההורה מהנתיב |
| `teacher_phone` כמערך עקבי | היום הוא מגיע לפעמים כמחרוזת מופרדת בפסיקים, לפעמים כ-`""` ולפעמים כ-`null` |
| `updated_at` ו-`previous_path` | כדי לזהות הזזה ושינוי שם של שלוחה בלי להשוות סריקות מלאות |
| סימון לשלוחה שנמחקה או הושבתה | כדי להבדיל בין שלוחה שנמחקה לשלוחה שלא נשלפה |

## בונוס

- **`/api/sum_calls/` עם פירוק יומי** (`group_by=day`), כדי לחסוך קריאה נפרדת לכל יום.
